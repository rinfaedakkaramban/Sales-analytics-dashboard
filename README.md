# 📊 Sales Analytics Dashboard

An interactive Sales Analytics Dashboard designed to track business performance, 
analyze sales trends, and provide actionable insights into revenue, orders, 
customers, products, and regions.

## 🎯 Project Overview

This dashboard provides a comprehensive view of sales performance through 
interactive filters, KPI cards, and visualizations.

The dashboard helps users understand:

- Overall revenue performance
- Quantity of products sold
- Total number of orders
- Average order value
- Customer performance
- Regional sales performance
- Product and category performance
- Sales and cost comparison
- Monthly sales and order trends
